We compiled a set of videos documenting what to buy, why, and how to build an electrified handcycle. These videos document our first electric-assist e-bike, which is front-wheel drive only. There are several things I would improve on this build, namely using a more modern motor with an L10 connector that is more reliable, but it is a great place to start. This is also probably the most affordable build possible. You can find the full playlist of videos [here](https://www.youtube.com/watch?v=xVTjULIFej0&list=PLCnUo3Wt5-NubyNFbIKPdzlgCyogU5E0I&index=1).
